🔒 App security hardening

V25

Strict page separation

Map, alerts, people, weather र news अलग pages भएकाले एक pageको bugले सबै UIलाई एउटै विशाल DOMमा असर गर्ने risk घट्छ।

Content Security Policy

V25 pagesले self-hosted JavaScript मात्र चलाउँछन्; object/embed/form execution बन्द छ र data fetch allowlisted hostsमा सीमित छ।

No source HTML execution

Official APIबाट आएको title/description textContentका रूपमा render हुन्छ; sourceले पठाएको HTML/JavaScript execute गरिँदैन।

No client secrets

Public static pagesमा API secret, password वा admin credential राखिएको छैन। Future backend credentials browser bundleमा कहिल्यै राख्नु हुँदैन।

Fail-safe data wording

Feed unavailable हुँदा appले “safe” infer गर्दैन। Missing/death totals conflict भए source/time र reconciliation status देखाइन्छ।

Security “100% unhackable” भनेर guarantee गर्न मिल्दैन। Production backend आएपछि rate limiting, WAF, dependency pinning, audit logs र load/security testing पनि अनिवार्य हुन्छ।
